## 体例

- **分章**：每篇一个 `##` 标题；篇首引用块是该篇最初的发表出处。
- **注释**：原书页下注以 `> **注 N**` 的引用块排在所注段落之后，编号按篇内顺序。
- **插图**：正文插图放在对应位置，文件在各自的 `images/` 目录下。
- **文本**：以原扫描件为准，仅做版式整理，不改动字句；原书排印或扫描不清之处保持原样。
